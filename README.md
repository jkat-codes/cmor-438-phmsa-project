Project Title: PHMSA's Incident Predictor

What is PHMSA? 
Pipeline and Hazardous Materials Safety Administration regulates pipelines, oversees hazardous materials, and enforces standards for the transport of these materials. PHMSA keeps and publishes reports regarding pipeline incidents. Each of these reports includes the pipe material, install decade, location, the operator, and the assigned cause (if identifiable at the time of publish). 

This Project in a Nutshell
This project will acquire, analyze and train several different machine learning models/algorithms/frameworks to accurately identify the cause of pipeline issue(s). The pipelines that I am going to focus on transport Natural Gas.
